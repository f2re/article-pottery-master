# Codex, Antigravity и прежний Gemini

Сверено 5 октября 2026 года по официальным руководствам: [Codex: навыки](https://learn.chatgpt.com/docs/build-skills), [Codex: AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [Antigravity: навыки](https://www.antigravity.google/docs/skills). Обе среды читают проектные навыки из `.agents/skills/`; у каждого есть `SKILL.md` с полями `name` и `description`. Файлы не требуют отдельной установки пакетов Python.

## Начало

Открой корень репозитория в установленном Codex или Antigravity. Дай задание: «Прочитай AGENTS.md и навык pottery-editor. Подготовь пакет статьи на тему …, используй реальные источники, не публикуй». Навыки подбираются по описаниям; явное чтение пути работает как резервный способ, когда версия интерфейса не обнаружила их автоматически. Не требуется копирование в домашнюю папку.

Доступ к интернету и возможность выделять отдельных исполнителей зависят от среды и её разрешений. При недоступном поиске не заполнять библиографию по памяти. При недоступных параллельных исполнителях выполнять роли последовательно и честно указать это. Навык — инструкция, а не доказательство независимого запуска агента. Подтверждение владельца всё равно обязательно.

## Роли и передача

| Навык | Результат | Что останавливает работу |
|---|---|---|
| pottery-editor | Задание, порядок этапов, журнал передачи | Неясная задача, конфликт версий |
| pottery-research | Источники и утверждения | Непроверенный оригинал или перевод |
| pottery-science | Методика и пределы выводов | Неправомерное обобщение |
| pottery-writer | Цельный текст | Нет доказательств для обещанного вывода |
| pottery-verifier | Независимая проверка фактов | Ошибка, отсутствующее подтверждение |
| pottery-style | Редактура голоса | Пустые фрагменты, выдуманный опыт |
| pottery-art | Задание, изображения и права | Подмена документального изображения |
| pottery-growth | Запрос, связи, версии для каналов | Потеря оговорок или фиктивные метрики |
| pottery-release | Проверенный файловый пакет | Нет актуальных отзывов и решения человека |

Параллелить можно поиск независимых источников и исследование форматов после задания. Финальная проверка работает только по замороженному пакету. Не разрешать двум исполнителям одновременно менять один файл. Возврат: конкретный дефект → ответственный → исправление → повторная проверка всех зависимых версий.

## Совместимость со старой схемой

Прежние `archeologist` заменены исследователем и проверяющим; `calligrapher`, `sculptor`, `tea-master` — единым автором; `visual-director` — арт-директором; `gallery-curator` — фактологической и стилевой проверками; `kiln-master` и `editor-in-chief` — координатором и выпуском.

Театрализованные файлы `.gemini/agents/` и `.gemini/workflows/`, а также старые команды по отдельным частям текста выведены из активного использования. Сохранён простой переход `.gemini/commands/pottery.toml`. Не переносить из истории неподтверждённые лимиты Ярмарки Мастеров, обязательный дзен и разрешение проверять факты «здравым смыслом».

Старые пользовательские `input/`, `sections/`, `review/` остаются нетронутыми. Для переноса создать новый пакет, прочитать старые материалы, разнести источники и утверждения и заново проверить. Наличие старого `FINAL_POST.md` не означает приёмки по новой системе.

## Проверки

```sh
python3 -m unittest discover -s tests -v
python3 scripts/editorial.py check articles/glaze-and-tea
python3 scripts/editorial.py digest articles/glaze-and-tea
python3 scripts/editorial.py export articles/glaze-and-tea
```

Экспорт без `--release` явно помечен черновиком. `check … --release` и `export … --release` требуют заполненной приёмки человеком; демонстрационный пакет намеренно её не имеет. Программа не входит в ВК и Ярмарку Мастеров и не публикует от имени владельца.

Структурные тесты навыков не заменяют проверку в конкретной установленной версии IDE. При этом обновлении не выполнялся интерактивный запуск установленного у владельца Codex или Antigravity; это отдельная проверка окружения.

## Качество содержания и плана

Демонстрационный материал переписан: объясняет выбор образцов, контроль, способ измерения, результат и область применения. Добавлена заполненная карточка опыта. ВК: один пост о переносимости результата, другой — о контроле. Ярмарка: самостоятельный разбор. Все тексты остаются черновиками, реальные отзывы не подделаны.

Девять навыков сохранены, новые обязательные агенты не добавлены. Шесть основных функций; наука и визуальная работа по необходимости; выпускающая роль направляет к программе, а не требует обязательного ещё одного генеративного прохода. Подготовка SEO перед автором; приёмка SEO/каналов — у независимого reader.

24 темы сохранены с состояниями готовности и открытыми зависимостями. T21 объединена с T02, T14 уточняет T02; T08/T13 дополняют T03. Два поста каждого слота имеют разные deliverable_id/обещания. Первая серия: T01, T02, T03, T23. Даты условные, показатели и частотности неизвестны. Наличие списка тем не объявляется готовностью статей.

## Проверено программно

Штатные проверки старой версии были выполнены перед изменениями. Локально на Python 3.13 выполнены 82 автоматических теста версии 3.1; все прошли. Новая серия проверяет не только прежние контракты, но и воспроизведённые в аудите дефекты, миграцию, публичный вывод, целостность файлов и синтаксис нативных адаптеров. Команда воспроизведения: `python3 -m unittest discover -s tests -v`.

Успешный check демонстрации — только корректный черновик. check --release должен отказать: нет реального автора, исполненных независимых отзывов, проверки форм и решения владельца. Положительные согласования создаются только в TemporaryDirectory тестов. Не переводить этот отказ в успех подстановкой выдуманных имён.

CI использует Python 3.11 и 3.13 без разрешения записи. Факт удалённого запуска подтверждается конкретным Actions run после коммита, а не самим наличием сценария.

## Что нельзя закрыть файлами правил

Фактическая независимость исполнителей, квалификация научного проверяющего и добросовестность чтения источников не устанавливаются сравнением строк ID. Реальная модель должна пройти evals/cases.json в установленной IDE; пока run-template имеет not_run. Для конкретной среды сохраняются версия, исходные ответы и вердикт независимого оценщика.

Принятый голос мастера, реальные снимки и протоколы для T03/T23, адреса каналов и метрики отсутствуют. Их нельзя заменить примерами и объявить пилот проведённым. approved.json пуст; specimens.md ясно помечен редакторскими примерами, не цитатами владельца.

Bamboo SEO остаётся источником товарных данных/аналитики; реализована только безопасная файловая передача публичной части. Нативный импорт схемы 2 принимающей стороной не заявлен и требует отдельного изменения того проекта. Старые согласования между инструментами не переносятся.

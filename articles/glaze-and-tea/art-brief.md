# Задание, не готовая съёмка

Пакет сейчас текстовый. Для иллюстрированной версии подготовить собственную условную схему: образец материала → подготовка → контакт с настоем → измерение. Отдельно обозначить, что готовая чаша требует собственного плана проверки.

Не изображать вымышленную лабораторию и не выдавать чужое фото за проведённый редакцией опыт. Не использовать музейные фотографии для этого вопроса: они не объясняют методику. Числа для схемы брать только из C1; обозначить условный масштаб.

После создания реального файла добавить запись в assets.json, ссылку Markdown в нужную версию статьи и повторить проверки. Макет оформления расположен в design/index.html; он не является изображением из этого пакета.

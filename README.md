# Pottery Master · редакция керамики

Версия **3.1**. Проверяемые статьи о керамике, научные и музейные разборы, самостоятельные публикации ВК и Ярмарки Мастеров. Python 3.11+, только стандартная библиотека. Скрипт не вызывает модель, не входит в аккаунты и не размещает посты.

## Начать с готового примера

```sh
python3 -m unittest discover -s tests -v
python3 scripts/editorial.py check articles/glaze-and-tea
python3 scripts/editorial.py export articles/glaze-and-tea
```

Последняя команда напечатает каталог `dist/`. Откройте в нём `public/preview.html`: статья, два разных поста ВК и самостоятельная версия Ярмарки в одном превью. Это черновики. Реальное имя автора, независимые отзывы и решение владельца не выдуманы; поэтому `status` и `check --release` для демонстрации возвращают код 1.

```sh
python3 scripts/editorial.py status articles/glaze-and-tea
python3 scripts/editorial.py route articles/glaze-and-tea
python3 scripts/editorial.py inventory articles/glaze-and-tea
```

`status` показывает весь доступный список блокеров, ответственных и следующих действий. Зелёный `check` подтверждает структуру черновика, а не истину и не приёмку. Проверка изображений включает сигнатуру; их содержание и права требуют проверки.

## Новая статья

```sh
python3 scripts/editorial.py init first-bowl
```

Откройте корень в Codex или Antigravity:

> Используй pottery-editor для first-bowl. Сначала проверь вопрос читателя и готовность источников, затем напиши полезный материал. Подготовь выбранные версии. Делегируй факты pottery-evidence, читательскую приёмку pottery-reader, науку pottery-scientific при необходимости. Покажи одно превью и свод замечаний. Не утверждай за владельца и не публикуй.

init создаёт пустой пакет с одной заметкой ВК, а не обязательный набор всех форматов. Другие версии добавляются через metadata.publications. До трёх независимых читающих исполнителей, без рекурсивного размножения; два цикла правок. При отсутствии субагентов повторная самопроверка обозначается честно и не выдаётся за независимую приёмку.

## Что исправлено после повторного аудита

Видимые подписи и маркировка входят в экспорт. Каждый отзыв подтверждает свою версию текста и превью; владелец принимает также неизменённый комплект отзывов. Адаптатор не принимает собственные версии. Два поста ВК представлены отдельными объектами. Локальные замеры и интервью не требуют веб-публикации и не копируются в публичный экспорт. Проверяются заглушки во всех обязательных полях; речевые формулы требуют контекстного решения вместо механического запрета.

Девять навыков остались, но обязательных функций шесть; научная и визуальная роли подключаются по задаче. Вместо шести отдельных формальных отметок — evidence, reader и условная science. Reader отвечает за полезность, понятность, интерес, голос, поиск, версии и оформление.

## Версии, перенос и безопасный выпуск

```sh
python3 scripts/editorial.py migrate articles/old-packet --new-slug migrated-packet
python3 scripts/editorial.py digest articles/migrated-packet
```

Миграция схемы 1 создаёт отдельную копию и сбрасывает согласования. Исходник не трогается; неизвестные обещания и подписи остаются незаполненными до проверки. Существующие каталоги и экспорты не перезаписываются.

После фактической приёмки человеком: `export <пакет> --release`. Проверить результат: `verify-export <каталог-экспорта> --package <пакет>`. Для передачи в другой редакционный инструмент — только public/ и манифест; первичные закрытые источники и согласования не переносятся автоматически. Ответственность на границе с bamboo-seo-skill описана в INTEGRATION.md.

Известные границы: реальные каналы и метрики не предоставлены; отсутствуют принятые владельцем образцы голоса; интерактивные запуски IDE не подменяются тестами Python. Начальный реестр исследований не объявляется полноценной научной базой всех 24 тем. Открытые зависимости перечислены в плане.

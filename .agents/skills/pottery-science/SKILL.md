# Научный редактор

Пути от корня. AGENTS.md обязателен.

Сначала помоги определить объект опыта, контроль, условия, измеряемую величину и предел переноса результата. Это консультация, не pass конечного текста. Нельзя по аннотации дорисовать методику или по фотографии заключить о пищевой безопасности.
Финальная science работает только после writer/growth/art и замораживания. Прочитай все версии, подписи и метаданные; сравни измеренное свойство с обещанным читателю. Научная ссылка не делает дегустацию проведённой, состав не равен пользе для здоровья. Исправления/отзыв публикации проверить.
Выход: отдельный финальный отзыв science с content_hash/public_hash, actor_id/run_id, статусом и обоснованием. Не принимается собственный авторский/адаптационный проход. Независимый фактологический приёмщик может дополнительно выполнить science при реальной компетенции; явно записать этот факт, не изображать двух людей.
